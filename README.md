# Первый урок: моя веб-страница

## Как открыть

1. Откройте эту папку в VS Code через **File → Open Folder…**.
2. Откройте `index.html` в Chrome: в Finder найдите эту папку и дважды нажмите файл.
3. Нажмите **«Показать приветствие»**. Текст на странице должен измениться.
4. В VS Code откройте `script.js`, замените текст внутри кавычек на своё приветствие и сохраните `⌘S`.
5. Вернитесь в Chrome и обновите страницу `⌘R`, затем проверьте кнопку ещё раз.

Если Chrome не обновляет сохранённые изменения, используйте жёсткое обновление `⌘ShiftR`.

## Что здесь происходит

- `index.html` задаёт содержание и структуру страницы. Теги вроде `<h1>` обозначают заголовок, `<p>` — абзац.
- `styles.css` отвечает за внешний вид: цвета, размеры, отступы и расположение.
- `script.js` добавляет поведение. `addEventListener("click", ...)` запускает код после нажатия; `textContent` меняет текст элемента.
- В HTML строка `<script ... defer>` подключает JavaScript после разбора страницы, а `defer` позволяет дождаться появления элементов.

## Практика

Сначала измените приветствие в `script.js`. Затем попробуйте изменить заголовок в `index.html` и цвет кнопки в `styles.css`. После каждого изменения сохраняйте файл и смотрите результат в Chrome.

Проверка урока: объясните своими словами, какой файл меняет текст, какой меняет цвет и какой хранит структуру страницы. Убедитесь, что нажатие на кнопку меняет абзац.

## Путь обучения

1. HTML, CSS, JavaScript и основы интерфейсов.
2. Git и GitHub: история изменений и публикация проектов.
3. JavaScript глубже, затем TypeScript и React.
4. Серверная часть: Node.js, API, базы данных и безопасность.
5. Интеграция ИИ через API: запросы к модели, интерфейс, обработка ошибок и защита ключей на сервере.
6. Портфолио: несколько законченных приложений и развёртывание.

Git в этой среде пока не запускается: macOS сообщает, что не установлены Command Line Tools. Для первого урока Git и Node.js не нужны; установку можно обсудить отдельно, когда дойдём до Git и серверной части.
